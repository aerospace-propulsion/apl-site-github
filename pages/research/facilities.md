## SNU Hypersonic Shock Tunnel (SHyST)

**High Mach, High enthalpy, High Reynolds shock tunnel**

<ul class="spec">
  <li>Driver Tube : Length 3000mm / Dia. 100mm / <strong>Maximum Pressure 300bar</strong></li>
  <li>Driven Tube : Length 8200mm / Dia. 100mm</li>
  <li>Nozzle : <strong>Mach ~6.8</strong> / Throat Dia. 32mm / <strong>Exit Dia. 340mm</strong> / Length 1400mm</li>
  <li>Test Section : Length 2400mm / Dia. 1000mm / Pressure 20Pa</li>
  <li>Schlieren visualization &amp; BOS measurement</li>
  <li>Planar Laser Scattering (PLS) / Rayleigh Scattering (RS)</li>
  <li>Temperature Sensitive Paint (TSP)</li>
  <li>Spectral Proper Orthogonal Decomposition (SPOD)</li>
  <li>Shock interaction / Boundary layer transition</li>
</ul>

## Reddy Shock Tunnel

**Small-scale &amp; educational-purpose hypersonic shock tunnel**

<ul class="spec">
  <li>Driver Tube : Length 400mm / Dia. 30mm</li>
  <li>Driven Tube : Length 600mm / Dia. 30mm</li>
  <li>Nozzle : Mach 6.3 / Throat Dia. 9.24mm / Exit Dia. 73.6mm / Length 159.5mm</li>
  <li>Test Section : Length 220mm / Depth 170mm / Height 170mm</li>
  <li>Both free-piston &amp; piston-driven modes are available</li>
  <li>Test models can be 3D printable</li>
  <li>2 pressure sensors in driven tube using NI DAQ system</li>
  <li>Schlieren visualization &amp; BOS measurement</li>
</ul>

\* Students interested in hypersonic flow experiment are welcome to contact Prof. Lee for using Reddy Shock Tunnel.
